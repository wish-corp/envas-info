# ゲストを CSV で一括登録できるようになりました

envas をご利用いただき、誠にありがとうございます。

## ゲストの CSV 一括インポート機能を追加しました

これまで一人ずつ追加いただいていたゲストの登録を、CSV ファイルから**まとめて取り込める**ようになりました。

事前にまとめておかれたゲストリストや招待状の管理表をそのままご利用いただけるため、登録作業の手間を大幅に削減できます。

ゲスト管理ページの「インポート」ボタンからご利用いただけます。

## 主な機能

- **最大 500 件まで一括登録**: 1 度の操作でまとめて取り込めます
- **テンプレート CSV のダウンロード**: モーダル内のリンクからテンプレートを取得できます。Excel で開いても文字化けしません
- **柔軟なファイル形式**: UTF-8 / Shift_JIS のいずれにも対応しています
- **エラー行の詳細表示**: 取り込めなかった行は、行番号・列名・原因とともに一覧表示されます

ご利用方法の詳細は、ヘルプサイトをご確認ください。
[https://help.envas.jp/guest/](https://help.envas.jp/guest/)
