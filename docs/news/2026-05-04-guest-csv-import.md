# ゲスト一覧の CSV インポート / エクスポートに対応しました

envas をご利用いただき、誠にありがとうございます。

## ゲスト情報を CSV で一括管理できるようになりました

ゲスト一覧ページで、CSV を使ったゲストの一括登録と一括更新ができるようになりました。
事前にまとめておかれたゲストリストをそのまま取り込んだり、登録済みのゲストを
CSV で書き出して一括で修正したりといった運用が手早く行えます。

ゲスト一覧ページの「インポート」「エクスポート」ボタンからご利用いただけます。

## 主な機能

- **新規一括登録**:「インポート」モーダルからテンプレート CSV を取得し、必要事項を
  埋めてアップロードすると、最大 500 件まで一括で登録できます
- **一括更新**:既にゲストが登録されている状態で「エクスポート」ボタンを押すと、
  現在のゲスト一覧 CSV がダウンロードできます。CSV 上で編集して再アップロードすると、
  ゲストID 列で対応する既存ゲストがまとめて更新されます
- **柔軟なファイル形式**:UTF-8 / Shift_JIS のいずれにも対応しています
- **エラー行の詳細表示**:取り込めなかった行は、行番号・列名・原因とともに一覧表示されます

## ヘッダーの仕様

CSV のヘッダー(1 行目)は `ゲストID,ゲスト名,敬称,肩書き` 固定です。
`ゲストID` 列を空にすると新規登録、エクスポートで取得した既存の ID を残しておくと
そのゲストの更新になります。

ご利用方法の詳細は、ヘルプサイトをご確認ください。
