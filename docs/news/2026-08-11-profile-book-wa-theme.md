# プロフィールブックに和テーマを追加しました

envas をご利用いただき、誠にありがとうございます。

プロフィールブックのデザインに、和装や和婚に合わせてお使いいただける**和テーマ**を追加しました。これまでの 4 種類とあわせて、5 種類のデザインからお選びいただけます。

## 和テーマについて

和紙のような生成りの地に、墨色の本文を組んだデザインです。本文は明朝体、見出しには筆書きの書体を当てています。

- 地には矢絣の地紋を敷き、ページの縁に菊をあしらいました
- 見出しの両端には梅を添えています
- FOOD MENU / DRINK MENU は墨色の帯に金の罫を重ねた設えにしました

白無垢や色打掛でのお写真、神前式や和婚の会場ともなじみやすいデザインです。

## ご利用方法

プロフィールブックの編集画面上部にあるデザインの選択欄から「wa」をお選びください。

入力済みの内容はそのまま引き継がれますので、作成の途中でもデザインだけを変更してお試しいただけます。
