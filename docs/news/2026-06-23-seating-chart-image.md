# 席次表画像ダウンロード機能をリリースしました

envas をご利用いただき、誠にありがとうございます。

## 席次表を画像としてダウンロードできるようになりました

席次表を PNG 画像としてダウンロードできる機能を追加しました。
ダウンロードした画像は、印刷して披露宴会場に掲示したり、ゲストへの案内に添付したりといった用途にお使いいただけます。

ダッシュボードの席次表カード、またはサイドメニューの「席次表画像ダウンロード」からご利用いただけます。

## 主な機能

- **テーマ × スタイルの組み合わせ**: 席次表の雰囲気を表すテーマと、席次表の見た目を表すスタイルを自由に組み合わせて、テーマ数✕スタイル数の組み合わせパターンの中からお好みのデザインを選べます
- **プレビューと拡大表示**: 画像をタップすると拡大して細部を確認できます
- **自動レイアウト調整**: テーブル数が多い場合でも、すべてのテーブルが画像内に収まるよう自動的にレイアウトを調整します
- **何度でも再ダウンロード**: 一度ご購入いただいた席次表は、テーマやスタイルを変更しても追加料金なしで何度でもダウンロードできます

## SNS 投稿で無料でご利用いただけます

現在、SNS に口コミを投稿いただくだけで、席次表画像ダウンロード機能を無料でご利用いただけます。

1. ページ下部の「席次表画像をダウンロードする」ボタンをタップします
2. 「お支払いに進む」の左隣にある「口コミで無料」ボタンをタップします
3. instagram など投稿した SNS のリンクを入力し、「送信する」ボタンをタップします
4. 運営が SNS の口コミ投稿を確認次第、ご利用が可能です

## 席次表ビューワの削除について

これまでプロフィールブック編集画面に設置していた席次表ビューワ（テーブル詳細モーダル付きのプレビュー）は、今回の席次表画像ダウンロード機能への統合に伴い削除しました。席次表のプレビューはプロフィールブックの編集ページのプレビューモードや、席次表画像ダウンロードページでご確認ください。
